# modelo-risco-credito-arvore-decisao
Projeto de Machine Learning para classificação de risco de crédito usando Árvore de Decisão, Python e Scikit-learn. Inclui tratamento de dados, criação da variável mau pagador, dummies, treino/teste, matriz de confusão e análise de métricas como acurácia, precision, recall e f1-score.
